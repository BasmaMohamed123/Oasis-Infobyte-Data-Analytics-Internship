# Oasis Infobyte - Data Analytics Internship

This repository contains the projects completed as part of my Data Analytics Internship at Oasis Infobyte.

## Projects

### Task 1 - Retail Sales Exploratory Data Analysis

An exploratory data analysis project focused on retail sales data, including data cleaning, customer analysis, product performance, sales trends, and profitability insights.

**Project Highlights:**
- Data cleaning and preprocessing.
- Exploratory Data Analysis using Python.
- Data visualization using Matplotlib, Seaborn, and Plotly.
- Interactive Streamlit Dashboard.
- Business insights and recommendations.

### Task 2 - Customer Segmentation

A customer segmentation project using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering to identify customer groups based on purchasing behavior.

**Project Highlights:**
- Data cleaning and preprocessing.
- RFM analysis.
- Log transformation and feature scaling.
- Elbow Method and Silhouette Score.
- K-Means clustering.
- Customer segment profiling and business recommendations.
